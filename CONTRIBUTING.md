# Contributing to Onda

Thank you for contributing to Onda.

## Before opening a pull request

- Keep each change focused and include tests when behavior changes.
- Run the repository's relevant checks locally.
- Explain the motivation, implementation, and verification in the pull request.

## Developer Certificate of Origin

Contributions must comply with the [Developer Certificate of Origin 1.1](https://developercertificate.org/). Sign off every commit to certify that you have the right to submit the contribution:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Git can add this line automatically:

```bash
git commit -s
```
